# harbor-roboteer Helm chart

Helm chart for deploying [harbor-roboteer](https://github.com/RiskIdent/harbor-roboteer) to Kubernetes.

## Installation

```bash
helm install harbor-roboteer oci://ghcr.io/riskident/charts/harbor-roboteer --version 1.0.0
```

See [`values.yaml`](values.yaml) for configuration options.
